# Historical prototype evidence

The existing reports, feature status counts and result indexes in this directory
describe the earlier Pumpkin-based prototype. They are retained with their
original engine hashes and must not be attributed to the independent engine.

The independent Rust implementation starts on branch `engine/independent`.
Its current implementation and validation status is described in the root
README. The version-pinned vanilla inventory and independently authored external
test tools remain reference inputs; passing historical tests is not current
coverage. New engine results must identify their exact source and executable.
